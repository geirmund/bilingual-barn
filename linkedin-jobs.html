Setup: Google OAuth Client ID

This page reads your Gmail directly from your browser — nothing is sent to a server. To do that it needs an OAuth Client ID that you create in your own Google Cloud project, scoped to read-only Gmail access on your own account.

  1. Open Google Cloud Console → Gmail API and click Enable (create a project first if you don't have one).
  2. Go to OAuth consent screen, choose External, and add yourself as a test user — testing mode is fine for personal use, no verification needed.
  3. Go to Credentials → Create Credentials → OAuth client ID → type Web application.
  4. Under Authorized JavaScript origins, add the exact origin you're opening this page from (e.g. http://localhost:8000 if served locally, or your GitHub Pages URL). file:// won't work — serve this file over http(s).
  5. Copy the generated Client ID and paste it below.
